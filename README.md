# ダンスのふりつけを作ろう！

曲に合わせて自分だけのダンスを作るためのステップガイドです。子ども向けにふりがな付きで分かりやすく解説しています。

## 機能

- ふりつけ作りの6ステップガイド
- ふりつけのコツ（音合わせ・強弱・表現・グループ）
- PWA対応（ホーム画面に追加してオフラインでも閲覧可能）
- スマホ対応のレスポンシブデザイン

## 技術構成

- HTML / CSS / JavaScript（単一ファイル構成）
- Service Worker によるオフラインキャッシュ
- Web App Manifest によるPWAインストール
- GitHub Pages でホスティング
